# Housing-Risk-Radar 부동산 위험 지수 통합 정리본


> 목적: 아파트 가격 예측을 위해 필요한 시장 신호 변수를 정리하고, 예측 가격과 실제 매매가의 차이를 활용해 지역별 가격 위험 신호를 해석한다. 이를 실거주자·투자자·정체도 관점으로 나누어 정리한다.
> 분석 대상: 서울특별시 25개 구의 월별 아파트 매매·전세·월세 데이터
> 핵심 방향: 전세가율, 매매-전세 괴리율, 가격 상승률 차이, 거래량 변화, 월세화 흐름을 가격 예측에 필요한 파생 변수로 생성한다. 이후 다음 월 평균 매매가 예측 결과와 실제 매매가의 차이를 확인하고, 이 차이를 실거주자·투자자·정체 구간의 위험 신호로 해석한다.

#### 0-1. 가격 예측 기반 분석 구조

본 프로젝트는 단순히 위험 지수를 먼저 만든 것이 아니라, 아파트 가격 예측에 필요한 시장 신호 변수를 생성하고, 이를 통해 다음 월 평균 매매가를 예측한 뒤, 예측 가격과 실제 매매가의 차이를 관점별 위험 신호로 해석하였다.

분석 흐름은 다음과 같다.

```text
1. 현재 월의 가격·전세·거래량·월세화 지표를 활용해 다음 월 평균 매매가 예측
2. 예측 가격과 실제 매매가의 차이 확인
3. 실제 매매가가 예측 가격보다 높은 지역을 가격 위험 신호로 해석
4. 해당 신호를 실거주자·투자자·정체도 관점으로 분리하여 위험 지수화
5. 머신러닝 모델로 위험 기준 라벨 분류와 위험 유형 군집화 수행
```

예측 가격은 전세가, 거래량, 월세화 흐름으로 설명되는 가격 수준으로 볼 수 있다.
따라서 실제 매매가가 예측 가격보다 높게 나타나는 지역은 가격을 뒷받침하는 시장 신호에 비해 매매가가 높게 형성되었을 가능성이 있다.

이 결과는 실거주자에게는 매수 부담, 투자자에게는 고점 매수 위험, 정체 구간에서는 고평가 정체 가능성을 확인하는 기초 신호로 활용된다.

#### 1-3. 중요 판단

- `jeonse_rate`는 단순 평균 가격 기준의 `avg_jeonse_deposit / avg_sale_price`가 아니라, 면적 차이를 보정한 `avg_jeonse_deposit_per_m2 / avg_sale_price_per_m2` 기준으로 계산된 전세가율이다.
- `gap_rate`는 `1 - jeonse_rate`와 같은 의미로 볼 수 있다.
- 따라서 전세가율과 매매-전세 괴리율은 면적 보정 기준 지표로 설명하는 것이 적절하다.
- 원자료 평균가격 기준으로 `매매가 > 전세가`는 899건, `전세가 > 매매가`는 1건이다.
- 따라서 `전세가 > 매매가`는 일반적인 흐름이라기보다 이상치 또는 특수 구간 확인용 변수로 보는 것이 적절하다.

#### 3. 공통 파생 변수 계산식

| 변수 | 계산식 | 해석 |
|---|---|---|
| `price_gap` | `avg_sale_price - avg_jeonse_deposit` | 양수이면 매매가가 전세가보다 높고, 음수이면 전세가가 매매가보다 높은 구간이다. |
| `gap_direction` | `price_gap > 0`: 매매가>전세가 / `price_gap < 0`: 전세가>매매가 | 괴리의 방향을 구분한다. |
| `sale_over_jeonse_gap_ratio` | `max(매매가 - 전세가, 0) / 매매가` | 매매가가 전세가보다 높은 정도를 나타낸다. |
| `jeonse_over_sale_gap_ratio` | `max(전세가 - 매매가, 0) / 전세가` | 전세가가 매매가보다 높은 특수 구간을 확인한다. |
| `gap_abs_ratio` | `abs(매매가 - 전세가) / max(매매가, 전세가)` | 방향과 관계없이 괴리 자체의 크기를 본다. |
| `monthly_ratio_diff` | 자치구별 `monthly_ratio.diff()` | 월세화 지표의 전월 대비 변화량이다. |
| `monthly_ratio_pct_change` | 자치구별 `monthly_ratio.pct_change()` | 월세화 지표의 전월 대비 변화율이다. |
| `monthly_shift_abs` | `abs(monthly_ratio_diff)` | 월세화 급변 정도를 나타낸다. |
| `purchase_burden_gap` | `avg_sale_price - avg_jeonse_deposit` | 실거주자가 매수할 때 추가로 부담해야 하는 가격 차이다. |
| `sale_growth_acceleration` | 이번 달 매매가 상승률 - 이전 달 매매가 상승률 | 매매가 상승 속도가 빨라지는지 확인한다. |
| `sale_growth_vs_market` | 해당 구 상승률 - 같은 월 서울 평균 상승률 | 서울 평균 대비 특정 구의 과열 정도를 확인한다. |

#### 4. 점수화 방식

위험 지수는 서로 단위가 다른 변수를 함께 사용하므로, 먼저 0~1 범위로 정규화한다.

```text
정규화 점수 = (해당 값 - 최솟값) / (최댓값 - 최솟값)
```

값이 높을수록 위험한 변수는 정규화 점수를 그대로 사용한다.

```text
위험 점수 = 정규화 점수
```

값이 낮을수록 위험한 변수는 방향을 뒤집어 사용한다.

```text
위험 점수 = 1 - 정규화 점수
```

예를 들어 전세가율은 낮을수록 위험하므로 다음과 같이 계산한다.

```text
전세가율 위험 점수 = 1 - 정규화(jeonse_rate)
```

#### 5-1. 가격 예측 실험

#### 5-1-1. 실험 목적

아파트 가격 예측에서 중요한 것은 단순히 다음 월 가격을 맞히는 것만이 아니라, 현재 가격이 전세가·거래량·월세화 흐름으로 설명 가능한 수준인지 확인하는 것이다.

따라서 현재 월의 가격 수준, 전세가, 거래량, 월세화 지표를 활용하여 다음 월 평균 매매가를 예측하였다.

#### 5-1-2. 타깃 변수

| 구분    | 내용                                                            |
| ----- | ------------------------------------------------------------- |
| 타깃 변수 | 다음 월 평균 매매가                                                   |
| 생성 방식 | 자치구별 `avg_sale_price`를 한 달 뒤로 이동하여 `next_month_sale_price` 생성 |
| 분석 단위 | 자치구 × 월                                                       |

#### 5-1-3. 입력 변수

| 변수 묶음    | 사용 변수                                                                          | 의미                  |
| -------- | ------------------------------------------------------------------------------ | ------------------- |
| 현재 가격 수준 | `avg_sale_price`, `avg_jeonse_deposit`                                         | 현재 매매가와 전세가 수준      |
| 가격 흐름    | `sale_growth_1m`, `jeonse_growth_1m`, `growth_gap_1m`                          | 매매가와 전세가의 상승 흐름     |
| 시장 지지 신호 | `jeonse_rate`, `gap_rate`                                                      | 전세가가 매매가를 얼마나 받쳐주는지 |
| 거래 흐름    | `sale_count`, `jeonse_count`, `sale_volume_growth_1m`, `rent_volume_growth_1m` | 거래가 유지되는지, 급변하는지    |
| 월세화 흐름   | `monthly_count`, `monthly_ratio`                                               | 임대시장 구조 변화          |

#### 5-1-4. 사용 모델

| 모델                      | 사용 이유                     |
| ----------------------- | ------------------------- |
| Linear Regression       | 기본적인 선형 가격 예측 기준선         |
| Random Forest Regressor | 변수 간 비선형 관계와 변수 중요도 확인 가능 |

#### 5-1-5. 가격 예측 결과의 해석

가격 예측 결과는 단순히 모델 성능을 확인하기 위한 것이 아니라, 이후 위험 신호 분석의 기준으로 사용하였다.

예측 가격은 전세가·거래량·월세화 흐름으로 설명되는 가격 수준으로 볼 수 있다.
실제 매매가가 예측 가격보다 높게 나타나는 지역은 가격을 뒷받침하는 시장 신호에 비해 매매가가 높게 형성되었을 가능성이 있다.

따라서 본 프로젝트에서는 예측 가격 대비 실제 매매가 초과율을 가격 위험 신호로 해석하였다.

#### 6. 1번 소주제: 실거주 방어력 지수

#### 6-1. 핵심 질문

> 이 지역은 실제로 거주해도 되는가?  
> 지금 매수해도 실거주 가치가 가격을 받쳐주는가?

#### 6-2. 문제

실거주자는 단기 수익보다 거주 안정성과 매수 부담이 중요하다.  
따라서 매매가가 높은지 여부만 보는 것이 아니라, 전세가가 매매가를 얼마나 뒷받침하는지, 매매가가 단기간에 과열되었는지, 월세화로 거주 비용 구조가 변하고 있는지를 함께 확인해야 한다.

#### 6-3. 세부 분석 포인트 5개

| 번호 | 세부 포인트 | 설명 | 필요 변수 |
|---:|---|---|---|
| 1 | 실거주 가치 평가 | 전세가율을 통해 매매가가 실제 거주 가치에 의해 얼마나 뒷받침되는지 확인 | `jeonse_rate`, `low_jeonse_rate_score` |
| 2 | 매수 부담 확인 | 매매가와 전세가 차이가 클수록 실거주자 매수 부담 증가 | `gap_rate`, `price_gap`, `purchase_burden_gap` |
| 3 | 고점 매수 위험 | 매매가 상승률이 높으면 단기 급등 이후 고점 매수 가능성 존재 | `sale_growth_1m`, `sale_growth_score` |
| 4 | 실수요 동반 여부 | 매매가 상승이 전세가 상승과 같이 움직이는지 확인 | `jeonse_growth_1m`, `growth_gap_1m`, `growth_gap_score` |
| 5 | 거주 비용 구조 변화 | 월세화 지표가 급증하면 전세 유지가 어려워지거나 주거비 부담 구조가 변할 수 있음 | `monthly_ratio`, `monthly_ratio_diff`, `monthly_shift_score` |

#### 6-4. 실거주자 위험 지수 확정 변수

|---|---|---|---|

| 매매가 상승률 점수 | `sale_growth_1m` | 단기 급등 지역의 고점 매수 가능성 확인 | 높을수록 위험 |

| 매매-전세 괴리율 점수 | 25% | 실거주자의 매수 부담을 직접적으로 보여줌 |

#### 6-8. 요약

실거주 방어력 지수는 전세가율과 매매-전세 괴리율을 중심으로 실거주자의 매수 부담을 판단한다. 여기에 매매가 상승률, 상승률 차이, 월세화 흐름을 추가해 고점 매수 위험과 거주 비용 구조 변화를 함께 반영한다.

#### 8. 3번 소주제: 정체는 안정인가, 위험인가?

#### 8-1. 핵심 질문

> 가격 정체는 안정 신호인가, 거래 위축 신호인가?

#### 8-2. 문제

정체는 이 프로젝트의 3번째 소주제이다.  
정체 구간은 가격 변화가 작다는 이유만으로 안정이라고 해석하면 안 된다.  
가격은 정체되어도 거래량이 감소하면 거래 위축 구간일 수 있고, 괴리율이 높은 상태로 정체되면 고평가가 해소되지 않은 위험 구간일 수 있다.

따라서 매매가, 전세가, 거래량, 괴리율, 월세화 변화를 함께 반영해 정체도를 5단계로 구분한다.

#### 8-3. 세부 포인트 5개

| 번호 | 세부 포인트 | 분석 내용 | 필요 변수 |
|---:|---|---|---|
| 1 | 매매가 정체 여부 | 매매가 상승률이 0에 가까운지 확인 | `sale_growth_1m`, `sale_stagnation_flag` |
| 2 | 전세가 정체 여부 | 전세가도 같이 정체되는지 확인 | `jeonse_growth_1m`, `jeonse_stagnation_flag` |
| 3 | 거래량 동반 여부 | 가격 정체가 거래 유지인지 거래 위축인지 구분 | `sale_volume_growth_1m`, `volume_drop_flag` |
| 4 | 고평가 정체 여부 | 가격은 정체인데 괴리율이 높은지 확인 | `gap_rate`, `high_gap_flag` |
| 5 | 월세화 변화 여부 | 가격은 정체인데 임대시장 구조가 변하는지 확인 | `monthly_ratio_diff`, `rent_shift_flag` |

#### 8-4. 정체도 확정 변수

| 변수 | 계산 방식 | 의미 |
|---|---|---|
| 매매가 정체 여부 | `abs(sale_growth_1m) <= 0.01` | 매매가가 거의 움직이지 않는 구간 |
| 전세가 정체 여부 | `abs(jeonse_growth_1m) <= 0.01` | 전세가가 거의 움직이지 않는 구간 |
| 거래량 감소 여부 | `sale_volume_growth_1m < 0` | 거래량이 감소한 구간 |
| 고괴리율 여부 | `gap_rate >= gap_rate 상위 25%` | 매매-전세 괴리율이 높은 구간 |
| 월세화 급변 여부 | `abs(monthly_ratio_diff) >= monthly_ratio_diff 절댓값 상위 25%` | 월세화 흐름이 급격히 변한 구간 |

#### 8-5. 정체도 위험 점수 가중치 초안

| 변수 | 가중치 | 이유 |
|---|---:|---|
| 매매가 정체 여부 | 25% | 가격이 움직이지 않는 핵심 조건 |
| 전세가 정체 여부 | 20% | 실거주 수요가 함께 정체되는지 확인 |
| 거래량 감소 여부 | 25% | 정체가 안정인지 거래 위축인지 구분 |
| 고괴리율 여부 | 20% | 고평가 상태가 해소되지 않는지 확인 |
| 월세화 급변 여부 | 10% | 임대시장 구조 변화 반영 |
| 합계 | 100% |  |

#### 8-6. 정체도 위험 점수 공식

```text
정체도 위험 점수 =
0.25 * 매매가 정체 여부
```

|---:|---|---|---|---|
| 1단계 | 활발 관찰 구간 | 활발 구간 | 가격 급등 여부 확인 | 수익 가능성 확인 |
| 2단계 | 완만 정체 구간 | 약한 정체 | 관망 후 매수 검토 | 안정적이나 단기 수익성 낮음 |
| 3단계 | 안정 정체 구간 | 안정 정체 | 매수 검토 가능 | 장기 보유 검토 |
| 4단계 | 신중 정체 구간 | 위험 정체 | 고점 매수 주의 | 유동성 점검 필요 |
| 5단계 | 거래 위축 정체 구간 | 거래 위축·고착 정체 | 매수 보류 검토 | 투자 보류 검토 |

#### 8-8. 정체 상황별 해석표

| 상황 | 실거주자 해석 | 투자자 해석 |
|---|---|---|
| 매매가 정체 + 거래량 유지 | 가격 안정 가능성. 괴리율이 낮으면 매수 검토 가능 | 큰 수익은 낮지만 안정적인 장기 보유 후보 |
| 매매가 정체 + 거래량 감소 | 적정 가격 판단이 어려워 매수 주의 | 팔기 어려운 유동성 위험 |
| 매매가 정체 + 괴리율 높음 | 실거주 가치 대비 비싼 가격이 유지되는 상태 | 가격 조정 위험 |
| 매매가 상승 + 전세가 정체 | 고점 매수 위험 | 투자 과열 또는 폭탄돌리기 가능성 |
| 전세가 정체 + 월세화 증가 | 거주 비용 구조 변화 주의 | 임대수익 구조 변화 가능성 |

#### 8-9. 요약

정체도 분석은 가격 변화가 작다는 사실만 보는 것이 아니라, 거래량 감소, 고괴리율, 월세화 급변이 함께 나타나는지 확인한다. 같은 정체라도 거래량이 유지되면 안정 정체에 가깝고, 거래량이 줄고 괴리율이 높으면 거래 위축 정체로 볼 수 있다.

#### 11. 관련 논문·뉴스 근거 정리

#### 11-1. 실거주자 관점 근거

- 전세가격과 전세/매매가비율은 주택시장 판단에 자주 사용되는 지표다.
- 전세가는 실제 거주 가치와 연결되고, 매매가는 투자 기대감과 시장 심리가 함께 반영될 수 있다.
- 따라서 전세가율이 낮고 괴리율이 높은 지역은 실거주 가치가 매매가를 충분히 뒷받침하지 못하는 지역으로 해석할 수 있다.

#### 11-2. 투자자 관점 근거

- 전세가율이 낮은 상황에서는 매매거래가 더 투자적인 성격을 가질 수 있다.
- 전세가율이 낮을수록 전세 보증금으로 매매가를 받치는 비율이 낮아져 더 많은 투자금이 필요하다.
- 매매가 상승률이 높지만 전세가 상승률이 낮은 구간은 투자 기대감 중심의 상승 가능성을 판단하는 데 활용할 수 있다.

#### 11-3. 월세화 관점 근거

- 최근 전월세 시장에서는 월세 비중이 높아지는 월세화 흐름이 나타난다.
- 월세화 지표는 단순한 가격 지표가 아니라 임대시장 구조 변화 지표로 활용할 수 있다.
- 따라서 월세화 급증 구간은 실거주자의 주거비 부담 변화와 투자자의 임대수익 구조 변화를 동시에 보여준다.

#### 11-4. 정체·거래량 관점 근거

- 주택가격과 거래량은 서로 영향을 주고받는다는 연구가 있다.
- 거래량 감소는 시장 참여자의 관망, 유동성 저하, 거래 위축 가능성을 보여주는 지표로 활용할 수 있다.
- 따라서 가격이 정체된 구간도 거래량 감소와 함께 나타나면 안정이 아니라 위험 정체로 해석할 수 있다.
