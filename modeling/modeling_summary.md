# 4주차 B팀 모델링 결과 요약

## 사용 데이터

- 입력 데이터: `modeling_dataset.csv`
- 이 파일은 3주차에서 생성한 모델링용 데이터셋이며, 이번 4주차 작업에서는 `monthly_merged.csv`를 다시 사용하지 않았습니다.
- 데이터 행 수: 875행
- 데이터 컬럼 수: 55개
- 분석 기간: 2023-06 ~ 2026-04
- 분석 지역 수: 25개 구

## 4주차 수행 내용

- 데이터 표준화: `StandardScaler` 적용
- K-Means 군집화: 5개 군집으로 지역·월별 위험 유형 구분
- 로지스틱 회귀: 위험/일반 지역 분류
- 랜덤 포레스트: 위험/일반 지역 분류 및 변수 중요도 확인
- 모델 성능 비교: accuracy, precision, recall, f1-score 비교
- 실거주자 관점 결과 해석: `resident_risk_index`, `resident_risk_grade` 활용
- 투자자 관점 결과 해석: `investor_risk_index`, `investor_risk_grade` 활용
- 정체도 보조 해석: `stagnation_score`, `stagnation_level` 활용

## 사용한 입력 변수

- `jeonse_rate`
- `gap_rate`
- `sale_growth_1m`
- `jeonse_growth_1m`
- `growth_gap_1m`
- `sale_volume_growth_1m`
- `rent_volume_growth_1m`
- `monthly_ratio`

## 실거주자 관점 해석

실거주자 관점에서는 `resident_risk_index`와 `resident_risk_grade`를 사용했습니다. 이 점수는 전세가율, 매매-전세 괴리율, 매매가 상승률, 상승률 차이, 월세화 흐름을 바탕으로 매수 부담과 거주 안정성을 확인하는 데 사용했습니다.

## 투자자 관점 해석

투자자 관점에서는 `investor_risk_index`와 `investor_risk_grade`를 사용했습니다. 이 점수는 매매가 상승이 전세가 상승과 함께 나타나는지, 거래량 변화가 급격한지, 괴리율이 과도한지를 확인하는 데 사용했습니다.

## 정체도 해석

최종 통합 정리본에 맞춰 `modeling_dataset.csv`에 이미 있는 가격 상승률, 거래량 변화율, 괴리율, 월세화 지표를 활용해 정체도 보조 지표를 생성했습니다. `stagnation_score`가 높을수록 가격 정체와 거래 위축, 고괴리율, 월세화 급변이 함께 나타나는 구간으로 해석할 수 있습니다.
