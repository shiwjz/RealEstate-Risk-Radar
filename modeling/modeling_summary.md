# 4주차 B팀 모델링 결과 정리

## 1. 사용 데이터

- 입력 파일: `modeling_dataset.csv`
- 분석 단위: 서울 25개 구 × 월별 데이터
- 행 수: 875개
- 기간: 2023-06 ~ 2026-04

## 2. 모델 입력 변수

`jeonse_rate`와 `gap_rate`는 `gap_rate = 1 - jeonse_rate` 관계라서, 모델 입력에서는 중복을 줄이기 위해 `gap_rate`를 핵심 괴리 변수로 사용했다.

사용 변수:

- `gap_rate`
- `sale_growth_1m`
- `jeonse_growth_1m`
- `growth_gap_1m`
- `sale_volume_growth_1m`
- `rent_volume_growth_1m`
- `monthly_ratio`

타깃 변수:

- `risk_target`: 전체 위험 점수 상위 25%를 위험 지역(1), 나머지를 일반 지역(0)으로 설정

## 3. 사용 모델

- K-Means: 지역별 위험 유형 군집화
- 로지스틱 회귀: 위험/일반 지역 분류
- 랜덤 포레스트: 위험/일반 지역 분류 및 변수 중요도 확인

## 8. 해석 방향

- K-Means는 정답 라벨 없이 지역·월 데이터를 위험 유형별로 묶는 데 사용했다.
- 로지스틱 회귀와 랜덤 포레스트는 직접 정의한 `risk_target`을 기준으로 위험 지역을 분류하는 데 사용했다.
- 랜덤 포레스트의 변수 중요도는 어떤 변수가 위험 지역 분류에 크게 작용했는지 설명하는 근거로 활용할 수 있다.
- 단, `risk_target`은 실제 부동산 사고 여부가 아니라, 프로젝트에서 정의한 위험 지수 상위 25% 기준이므로 보고서에서는 “위험 신호가 높은 지역”으로 해석하는 것이 적절하다.
