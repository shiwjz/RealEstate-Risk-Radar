# Housing-Risk-Radar

## 프로젝트 소개

본 프로젝트는 아파트 매매 실거래가와 전세 실거래가 데이터를 활용하여 지역별 매매-전세 괴리율을 분석하고, 이를 바탕으로 부동산 시장의 위험도를 모델링하는 머신러닝 기반 데이터 분석 프로젝트입니다.

전세가는 실제 거주 가치와 밀접한 관련이 있는 지표로 볼 수 있습니다. 반면 매매가는 투자 기대감, 시장 심리, 지역 개발 가능성 등 다양한 요인에 의해 상승할 수 있습니다. 따라서 전세가에 비해 매매가만 과도하게 상승한 지역은 실거주 가치보다 투자 수요가 크게 반영되었을 가능성이 있습니다.

본 프로젝트에서는 이러한 매매가와 전세가 사이의 차이를 **매매-전세 괴리율**로 정의하고, 이를 활용하여 지역별 부동산 위험 지수를 생성하는 것을 목표로 합니다.

---

## 프로젝트 목적

본 프로젝트의 주요 목적은 다음과 같습니다.

1. 공공 데이터를 활용하여 아파트 매매가와 전세가 데이터를 수집한다.
2. 지역별, 월별 매매가와 전세가의 흐름을 분석한다.
3. 매매-전세 괴리율, 전세가율, 가격 상승률 등의 변수를 생성한다.
4. 생성된 변수를 바탕으로 지역별 부동산 위험 지수를 설계한다.
5. 머신러닝 모델을 활용하여 위험 지역을 분류하고 결과를 해석한다.

---

## 분석 배경

최근 부동산 시장에서는 특정 지역의 매매가격이 빠르게 상승하는 반면, 전세가격은 상대적으로 크게 오르지 않는 현상이 나타나기도 합니다. 이러한 경우 매매가격에는 실거주 가치보다 투자 기대감이 과도하게 반영되었을 가능성이 있습니다.

따라서 본 프로젝트는 다음과 같은 질문에서 출발합니다.

> 매매가는 빠르게 상승했지만 전세가는 따라오지 못한 지역은 부동산 시장에서 더 높은 위험을 가질까?

이를 분석하기 위해 매매가격과 전세가격의 괴리 정도를 수치화하고, 지역별 위험도를 비교하고자 합니다.

## 주요 생성 변수

본 프로젝트에서는 단순히 기존 데이터를 사용하는 것이 아니라, 분석 목적에 맞는 변수를 새롭게 생성합니다.

| 변수명 | 설명 |
|---|---|
| 평균 매매가 | 지역별 월별 평균 아파트 매매가격 |
| 평균 전세가 | 지역별 월별 평균 아파트 전세가격 |
| 전세가율 | 평균 전세가 / 평균 매매가 |
| 매매-전세 괴리율 | 1 - 전세가율 |
| 매매가 상승률 | 이전 기간 대비 매매가격 변화율 |
| 전세가 상승률 | 이전 기간 대비 전세가격 변화율 |
| 상승률 차이 | 매매가 상승률 - 전세가 상승률 |
| 거래량 변화율 | 이전 기간 대비 거래량 변화율 |
| 위험 지수 | 괴리율, 상승률, 거래량 등을 조합한 위험 점수 |

---

## 위험 지수 설계 방향

본 프로젝트에서는 다음과 같은 기준을 활용하여 부동산 위험 지수를 설계합니다.

```text
위험 지수 =
매매-전세 괴리율
+ 매매가 상승률
- 전세가 상승률
+ 거래량 변화율
```

즉, 다음 조건을 만족하는 지역일수록 위험도가 높다고 판단합니다.

- 매매가와 전세가의 차이가 큰 지역
- 매매가격이 빠르게 상승한 지역
- 전세가격 상승률은 상대적으로 낮은 지역
- 거래량이 급격하게 증가한 지역
